Alt Text Generator AI

Write SEO-friendly alt text for every image on your Odoo website, in one click.

Missing alt text hurts your search ranking and makes your site harder to use with a screen reader. This app looks at each image and writes a clear, accurate description for you, in your language.

See what needs alt text

The Bulk Alt Text screen lists every page image and product image that is missing alt text, with a thumbnail of each one. Tick the ones you want and press one button. You see exactly which images you are writing for, and the text that was written.

Find it under Website > Site > Bulk Alt Text.

Rewrite old alt text when you want to

Existing alt text is never touched unless you ask. Tick Show images with alt text to list those images with their current text, then pick the ones you want to write again, for example after changing your site language or tone.

Generate from your pages list

Select one or several website pages, open Actions and choose Generate Missing Alt Text. Only images without alt text are filled in. The same button is also on every page form.

Product images too

With Website Sales installed, extra product images get a Generate Alt Text button. Odoo uses the image name as the shop's alt text, so the generated description becomes what search engines and screen readers see on your product page.

Simple settings

Paste your API key, pick one of 131 languages and you are ready. Your remaining credits are shown right in the settings and on the Bulk Alt Text screen, with a link to get more.

How it works

1. Get an API key

Create a free account at alttextgeneratorai.com and copy your API key. New accounts include free credits.

2. Add it in Odoo

Go to Settings > Alt Text Generator AI, paste the key, choose your language and save.

3. Generate

Open Website > Site > Bulk Alt Text, tick the images and press Generate Alt Text.

Features

  • Alt text for website page images and, with Website Sales, extra product images.
  • Bulk screen with thumbnails, per-image checkboxes and the generated text shown.
  • Only fills in missing alt text. Rewrites existing text only when you choose to.
  • 131 languages.
  • Credits left shown live, with a link to get more. One credit per image.
  • Large images are resized automatically before they are sent.
  • Stops cleanly when credits run out and keeps everything already done.

External service and privacy

This app uses the AltTextGeneratorAI service (alttextgeneratorai.com) to describe images with AI. An image is sent to that service only when you press a Generate button and nothing is sent in the background. It needs an API key from your own AltTextGeneratorAI account. Read the privacy policy.
